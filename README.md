# The Couple Check

A private, mobile-friendly couples compatibility and love-language reflection test.

## Features
- Two-person private partner-code flow — each person can take the test separately on their own device, with answers kept hidden until both finish and unlock the shared reveal
- 20 relationship questions
- Compatibility scoring across communication, trust, affection, lifestyle, future, conflict, and intimacy
- Informal five-category love-language profile
- Shared strengths and growth-area analysis
- Five personalized connection tasks
- No backend: Person 1's answers are encoded into the partner code and transferred directly to Person 2; the app does not submit responses to a server

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages using the `main` branch and repository root.

> This is an informal conversation/reflection tool, not a clinical or validated relationship assessment.
